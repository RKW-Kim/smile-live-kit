SMILE LIVE KIT - run order
1) Double-click  run-bridge.bat   (starts data + serves pages; status http://localhost:8787)
2) OBS -> Scene Collection -> Import... -> ../obs/Smile-Trading-Kit.json -> select Smile Trading Kit
3) Two clicks: double-click WEBCAM-1 (pick camera) and chat (paste chat-box URL)
Switch scenes: Ctrl+Alt+F1..F5
Key is in secrets.env (git-ignored, auto-loaded). New brand: edit brands/<x>/brand.json then copy to brand.json.
