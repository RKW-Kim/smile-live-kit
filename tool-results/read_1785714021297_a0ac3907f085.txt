   103→## 4. TECHNICAL INFRASTRUCTURE
   104→
   105→### 4.1 The VPS Streaming Model (Core Innovation)
   106→
   107→The 24/7 stream runs entirely on a Virtual Private Server (VPS), not on local hardware:
   108→
   109→```
   110→
   111→Record → Edit → Upload to Cloud Storage → VPS loops via FFmpeg → YouTube Live
   112→
   113→```
   114→
   115→**How it works:**
   116→- FFmpeg loops pre-recorded video files indefinitely using `-stream_loop -1`
   117→- Outputs via RTMP directly to YouTube Live
   118→- Systemd service auto-starts FFmpeg on VPS boot; watchdog script auto-restarts on crash
   119→- The stream survives local power cuts, internet outages, and hardware failures — the VPS is in a data center with redundant power and connectivity
   120→
   121→**VPS Requirements:**
   122→| Resolution | RAM | Monthly Cost | Provider Examples |
   123→|------------|-----|-------------|-------------------|
   124→| 720p | 4 GB | $10–16 | Hetzner, DigitalOcean, Vultr, Contabo |
   125→| 1080p | 8 GB | $20–30 | Same providers |
   126→
   127→**The dad's existing VPS may already be sufficient if it has 4GB+ RAM.**
